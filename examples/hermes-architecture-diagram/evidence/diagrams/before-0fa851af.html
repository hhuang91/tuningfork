Pinboard Architecture

Photo-sharing application infrastructure layout

Application Layer

  • • Node.js API on ECS Fargate
  • • Managed by sg-app security group
  • • Stateless service architecture

AWS Infrastructure

  • • Region: us-east-1
  • • CloudFront for global distribution
  • • ALB for traffic distribution
  • • S3 for scalable photo storage

Data Persistence

  • • PostgreSQL on RDS for metadata
  • • ElastiCache Redis for sessions
  • • S3 for binary image assets
